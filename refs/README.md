# Reference captures

Drop real War Thunder screenshots here, named to match the framings in
`tools/shoot.mjs` (`hero.png`, `dogfight.png`, `low.png`, `cockpit.png`,
`clouds.png`, `ground_attack.png`, `sunset.png`, `water.png`, `damage.png`,
`hud.png`).

When files are present, the critique loop performs a genuine blind A/B: the
critic describes both frames without being told which is which, commits to a
verdict, and only then learns which was ours.

When this directory is empty the critic scores against `docs/VISUAL_RUBRIC.md`
alone and says so explicitly rather than claiming a comparison it did not make.
